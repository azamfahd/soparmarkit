# دليل تحويل المشروع إلى تطبيق مستقل (سطح مكتب وهاتف أندرويد APK) 🚀

يرحب بك هذا الدليل الشامل لشرح كيفية تشغيل هذا المشروع **كمشروع مستقل بالكامل** على جهازك الشخصي، وتحويله إلى:
1. **تطبيق سطح مكتب مستقل (Desktop App)** مدعوم بـ **لغة بايثون (Python)** وواجهات الويب فائقة السرعة مع ميزة استيراد وتصدير ملفات قواعد البيانات ناتيفياً.
2. **تطبيق أندرويد احترافي (APK)** بأسهل وأسرع الطرق مع الحفاظ الكامل على دقة التصميم، الأداء العالي، والوصول الكامل للكاميرا والمستودع.

---

## 📋 الخطوة التمهيدية الأولى: تجهيز ملفات المشروع محلياً

قبل البدء في أي عملية تحويل، يجب تحميل المشروع على حاسوبك وبناء واجهات الويب (الملفات الثنائية):

1. **تحميل المشروع**: قم بتحميل ملف الـ ZIP للمشروع من خلال قائمة الإعدادات في AI Studio، أو اسحبه عبر مستودع GitHub.
2. **تثبيت الملحقات**: افتح سطر الأوامر (Terminal) في مجلد المشروع وشغّل:
   ```bash
   npm install
   ```
3. **بناء واجهات التطبيق (هام جداً)**: قم بعمل تجميع (Build) لملفات الويب لإنتاج مجلد `dist` المحتوي على الواجهات المصممة بـ React و Tailwind:
   ```bash
   npm run build
   ```

## 💻 الخيار الأول: تشغيل التطبيق كتطبيق سطح مكتب احترافي مدعوم بـ Python 🐍
لقد قمنا بتوفير ملف `app.py` جاهز ومدمج داخل جذور المشروع. يقوم هذا الملف بتشغيل خادم بايثون محلي خفيف لخدمة الملفات بشكل آمن بالكامل دون إنترنت، ويفتح نافذة نظام مستقلة وسريعة مع ربط مباشر ومميز مع واجهات الويب.

### المميزات الحصرية في نسخة البايثون:
* **سرعة فائقة واستقلالية تامة**: يعمل كتطبيق أصيل على نظامك دون الحاجة لمتصفح خارجي.
* **تصدير واستيراد ذكي**: قمنا ببرمجة جسر تواصل ذكي (API Bridge) بحيث أنه عند تشغيل نسخة البايثون، تظهر واجهة استيراد وتصدير ملفات النسخ الاحتياطية وتتعامل مع **نوافذ الحفظ والاختيار الأصلية لنظام التشغيل (Windows/Mac/Linux)** مما يسهل نقل البيانات وتصديرها بمرونة واحترافية متناهية.

### طريقة التشغيل:
1. **تثبيت مكتبة العرض**:
   ```bash
   pip install pywebview
   ```
2. **تشغيل التطبيق**:
   ```bash
   python app.py
   ```

## 📱 الخيار الثاني: تحويل المشروع إلى تطبيق أندرويد APK احترافي

لديك طريقتان لتحويل التطبيق إلى APK واختيار الأنسب لك:

### 🌟 الطريقة (أ): استخدام الكاباسيتور (CapacitorJS) - [الطريقة الرسمية والمستحسنة تقنياً]
هذه هي الطريقة القياسية لشركات البرمجة الكبرى لتحويل تطبيقات React/Vite إلى تطبيقات هواتف احترافية. ستحصل على تطبيق سريع جداً، ذو كفاءة طاقة عالية، ومستقر مع معالجة الكاميرا والوصول للذاكرة بشكل ممتاز.

#### خطوات التحويل خطوة بخطوة:
1. **تثبيت الكاباسيتور في المشروع**:
   ```bash
   npm install @capacitor/core @capacitor/cli
   ```
2. **تهيئة الكاباسيتور**:
   ```bash
   npx cap init "نقاط البيع والمستودعات" "com.smartpos.app" --web-dir=dist
   ```
3. **إضافة منصة الأندرويد**:
   ```bash
   npm install @capacitor/android
   npx cap add android
   ```
4. **مزامنة الملفات وتحديث الكود**:
   ```bash
   npx cap sync
   ```
5. **بناء وتصدير ملف الـ APK**:
   * قم بتثبيت برنامج **Android Studio** على جهازك.
   * افتح مشروع الأندرويد الذي تم إنشاؤه عبر تشغيل الأمر:
     ```bash
     npx cap open android
     ```
   * سيفتح تطبيق أندرويد ستوديو تلقائياً. من شريط الأدوات العلوي اختر:
     `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`.
   * سيتم تجميع التطبيق في ثوانٍ معدودة وإنتاج ملف الـ APK الجاهز للنشر على هاتفك!

### 🐍 الطريقة (ب): استخدام بايثون لبناء الـ APK (Kivy + Webview + Buildozer)
إذا كنت تفضل استخدام بايثون كلياً لتغليف وتصدير التطبيق للأندرويد، فقد قمنا بتجهيز ملف `main.py` وملف الإعدادات الخاص به `buildozer.spec` في جذور مشروعك.

يستخدم هذا الخيار مكتبة **Kivy** وواجهة **Pyjnius Native** لاستدعاء الـ WebView الأصلي الخاص بنظام أندرويد داخل كود بايثون، كما يقوم بإدارة طلب صلاحيات الكاميرا والذاكرة ناتيفياً عبر بايثون لضمان تشغيل الماسح الضوئي بشكل مرن وسريع.

#### خطوات التحويل باستخدام Buildozer (مستحسن استخدام نظام Linux أو خدمة Google Colab المجانية):

بما أن أداة `Buildozer` تتطلب نظام تشغيل Linux لتجميع التطبيق، فإن أسهل طريقة لبنائه مجاناً بدون تثبيت أي شيء هي استخدام منصة **Google Colab**:

1. قم برفع مجلد المشروع كاملاً إلى حساب Google Drive الخاص بك.
2. افتح مفكرة Google Colab جديدة، وقم بربطها بحساب Google Drive الخاص بك:
   ```python
   from google.colab import drive
   drive.mount('/content/drive')
   ```
3. قم بتثبيت متطلبات Buildozer في بيئة عمل Google Colab:
   ```bash
   !pip install buildozer
   !pip install cython==0.29.33
   !sudo apt-get install -y \
       git \
       zip \
       unzip \
       openjdk-17-jdk \
       autoconf \
       libtool \
       pkg-config \
       zlib1g-dev \
       libncurses5-dev \
       libssl-dev \
       unzip
   ```
4. انتقل إلى مجلد مشروعك المرفوع في بيئة العمل:
   ```bash
   %cd /content/drive/MyDrive/اسم_مجلد_مشروعك
   ```
5. تأكد من بناء مجلد الويب أولاً عبر npm لتوليد ملفات `dist` الهامة:
   *(إذا لم تكن الأدوات مثبتة في Colab يمكنك تثبيتها وبناء المشروع في دقيقة واحدة)*.
6. ابدأ عملية بناء الـ APK عبر تشغيل بايثون أداة بيلدوزر:
   ```bash
   !buildozer -v android debug
   ```
7. عند انتهاء البناء بنجاح، ستجد ملف الـ APK الاحترافي جاهزاً للتحميل والتثبيت داخل مجلد `bin/` في مشروعك!

## 🛡️ نصائح وتنبيهات أمنية هامة للتشغيل الاحترافي:
* **صلاحيات الكاميرا**: لقد قمنا ببرمجة معالجة الصلاحيات مسبقاً في ملف `main.py` البايثون وفي ملفات التكوين. عند تثبيت الـ APK على هاتفك، سيسألك نظام الأندرويد لأول مرة عن السماح باستخدام الكاميرا للماسح الضوئي، بمجرد الموافقة سيعمل الماسح بشكل فوري واحترافي تماماً.
* **حفظ البيانات**: يستخدم هذا التطبيق محرك قواعد بيانات محلي فائق السرعة والأمان يعتمد على متصفح الأندرويد والـ WebView (IndexedDB عبر Dexie)، مما يعني أن بياناتك وسجلات مبيعاتك ومخازنك تظل آمنة محلياً بالكامل على هاتفك ولا تغادر جهازك أبداً، وتستطيع تصدير نسخ احتياطية بضغطة زر وحفظها على ذاكرة الهاتف بشكل ناتيف وسهل.

أتمنى لك تجربة موفقة ونجاحاً باهراً في إدارة تجارتك ومبيعاتك عبر تطبيقك الخاص والذكي! 🌟
