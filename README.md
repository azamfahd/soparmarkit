# 📊 النظام المحاسبي الذكي (Smart Accounting & POS System)

نظام محاسبي وإدارة مبيعات متكامل يعمل بالكامل داخل المتصفح (100% Local & Offline First) مزود بـ **وكيل محاسبي ذكي** للتحليل المالي وإدارة المخزون والتنبؤ المالي.

---

## 🌟 الميزات الرئيسية
- 🛒 **نقطة البيع (POS):** بيع سريع، طباعة الفواتير، اختيار طريقة الدفع، وخصومات مرنة.
- 📦 **إدارة المخزون:** متابعة المنتجات، الباركود، وحد الطلب الأدنى للتنبيه عند النفاد.
- 👥 **العملاء والموردون:** إدارة الديون والذمم، كشوفات الحساب، وسندات القبض والصرف.
- 🤖 **الوكيل المحاسبي الذكي:** تحليل الأرباح، جودة البيانات، واستجابة لمختلف الاستفسارات المالية.
- 📥 **الاستيراد الذكي:** قراءة وتدقيق الفواتير المطبوعة والمستندات بمرونة عالية.
- 📲 **دعم PWA / APK:** إمكانية التثبيت كتطبيق هاتف ذكي عبر PWA أو تحويله إلى APK بسهولة.
