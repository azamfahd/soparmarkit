# بقالة بلس - نظام محاسبي متكامل

نظام محاسبي شامل لإدارة البقالات والمتاجر الصغيرة، مع دعم كامل للعمل دون اتصال بالإنترنت (PWA) وقاعدة بيانات SQLite موحدة.

## المميزات الرئيسية

- **إدارة المخزون**: تتبع المنتجات والمخزون والأسعار
- **نقطة البيع (POS)**: واجهة سهلة لإتمام المبيعات والعمليات
- **إدارة الزبائن والديون**: تتبع الزبائن والديون والمدفوعات
- **التقارير والإحصائيات**: رؤى شاملة عن المبيعات والأرباح
- **العمل دون اتصال (PWA)**: يعمل بدون إنترنت مع مزامنة تلقائية
- **قاعدة بيانات موحدة**: SQLite كمصدر وحيد للبيانات
- **واجهة سهلة الاستخدام**: تصميم حديث وسريع الاستجابة

## المتطلبات

- **Node.js**: الإصدار 18.0.0 أو أحدث
- **npm** أو **pnpm**: مدير الحزم

## التثبيت والتشغيل المحلي

### 1. استنساخ المشروع أو فك الضغط

```bash
unzip soparmarkit.zip
cd soparmarkit
```

### 2. تثبيت التبعيات

```bash
npm install
# أو
pnpm install
```

### 3. إنشاء ملف .env (اختياري)

```bash
cp .env.example .env
```

### 4. تشغيل التطبيق في وضع التطوير

```bash
npm run dev
```

سيتم فتح التطبيق على `http://localhost:5173`

### 5. بناء التطبيق للإنتاج

```bash
npm run build
```

### 6. تشغيل التطبيق في وضع الإنتاج

```bash
npm start
```

## البنية المعمارية

### Frontend (React + TypeScript)
- واجهة مستخدم حديثة باستخدام React و TailwindCSS
- دعم PWA كامل مع Service Worker
- عمل بدون اتصال بالإنترنت

### Backend (Express.js + SQLite)
- API RESTful شامل
- قاعدة بيانات SQLite محلية
- معالجة المعاملات الآمنة

### قاعدة البيانات
- **products**: المنتجات والأسعار والمخزون
- **customers**: بيانات الزبائن والأرصدة
- **sales**: سجل المبيعات
- **sale_items**: تفاصيل عناصر كل عملية بيع
- **debts**: سجل الديون والمدفوعات
- **inventory_logs**: سجل التغييرات في المخزون
- **settings**: إعدادات التطبيق

## متغيرات البيئة

| المتغير | الوصف | القيمة الافتراضية |
|---------|-------|------------------|
| `PORT` | المنفذ الذي يستمع عليه التطبيق | 3000 |
| `DATABASE_PATH` | مسار ملف قاعدة البيانات SQLite | grocery.db |
| `NODE_ENV` | بيئة التشغيل (development/production) | development |

## النشر على Railway

### 1. إنشاء حساب على Railway

زر الموقع: https://railway.app

### 2. ربط مستودع GitHub

- اضغط على "New Project"
- اختر "Deploy from GitHub"
- اختر المستودع الخاص بك

### 3. إعداد متغيرات البيئة

في لوحة التحكم على Railway:
- `PORT`: سيتم تعيينه تلقائياً
- `DATABASE_PATH`: `/tmp/grocery.db` (للتخزين المؤقت)
- `NODE_ENV`: `production`

### 4. النشر

سيتم النشر تلقائياً عند كل push إلى الفرع الرئيسي.

## الاستخدام

- تسجيل الديون والمدفوعات

### سجل المبيعات
- عرض جميع المبيعات
- طباعة الفواتير
- عرض تفاصيل كل عملية

## العمل دون اتصال (PWA)

التطبيق يدعم العمل بدون اتصال بالإنترنت:

1. **التثبيت**: اضغط على "تثبيت التطبيق" في الشريط العلوي
2. **الاستخدام**: استخدم التطبيق بشكل طبيعي حتى بدون إنترنت
3. **المزامنة**: عند استعادة الاتصال، يتم مزامنة البيانات تلقائياً

## استكشاف الأخطاء

### المشروع لا يعمل
```bash
# تأكد من تثبيت التبعيات
npm install

# امسح node_modules والـ package-lock.json
rm -rf node_modules package-lock.json
npm install
```

### خطأ في قاعدة البيانات
```bash
# احذف ملف قاعدة البيانات وأعد تشغيل التطبيق
rm grocery.db
npm run dev
```

### مشاكل الاتصال
- تأكد من أن الخادم يعمل على المنفذ الصحيح
- تحقق من متغيرات البيئة
- تحقق من اتصالك بالإنترنت
